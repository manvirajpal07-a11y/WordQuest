# WordQuest 🎮

WordQuest is a simple word-guessing game built using Python. The game randomly selects a word, and the player has to guess the word by entering one letter at a time.

## Features
- Random word selection
- Guess one letter at a time
- Displays correctly guessed letters
- Allows a maximum of 6 wrong guesses
- Prevents repeated guesses
- Displays a winning or losing message
## Technologies Used
- Python

## How to Run
1. Download the WordQuest.py file.
2. Make sure Python is installed on your computer.
3. Run the program using Python.
4. Enter one letter at a time to guess the hidden word.
